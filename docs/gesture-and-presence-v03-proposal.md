# ジェスチャー・人物検出・モニター表示（v0.3提案）

2026-10-11 ユーザーとの設計会話を反映。従前の「人物不在30秒で終了」は変更する。

## 決定した動作
- CCAPIのモニター画像を表示し、案内・カウントダウン・残り枚数をオーバーレイする。
- 撮影のトリガーは設定したジェスチャー（グー、ピースなど）。ジェスチャーの解除・再検出を経て次の撮影を受け付ける。
- 最大5枚。
- **有効な撮影ジェスチャーが30秒間ないとセッション終了**。人物が画面内にいても終了する。
- 0枚の場合はアップロードせず待機へ戻る。
- セッション終了時はJPEGの保存完了を確認し、撮影枚数と画像一覧を含むready.jsonを発行する。
- C#アップローダーは同一セッションの全写真をまとめてアップロードし、受取QRコードを印刷する。
- 撮影後の写真一覧・選択画面は不要。
- **人物がいる/いないの監視は、撮影タイマーと独立した状態情報として保持する**。人物不在だけではセッション終了を判定しない。

## 画面の状態案
- idle: カメラの前に立つ案内
- capturing: ジェスチャー案内・カウントダウン・撮影済み枚数
- finalizing: 撮影終了案内
- uploading: QR印刷処理中の案内
- printed: レシート受取案内

## 状態情報案
- personPresent: boolean（検出信頼度・瞬断対策は今後設計）
- gestureDetected: string | null
- photoCount: integer
- sessionState: idle/capturing/finalizing/uploading/printed
- secondsRemaining: integer

## 確認が必要な点
- 「撮影ジェスチャーで30秒タイマーをリセット」するタイミング（認識時か撮影保存完了時か）
- 0枚で待機に戻る場合の人物在席中の再開条件
- 5枚到達・印刷完了後の次セッション受付条件
- CCAPIライブビューの既存表示機能と外部Webカメラでの人物検出方式
